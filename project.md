# Beholder Adventure

## Overview
This project's goal is to create a game using the the godot game engine.
Using the godot scripting language the goal is to create a game that is similar to the "Kupo Kupo Adventure" game from Final Fantasy XIV.

Both Windows and WSL have powershell installed so this is our prefered scripting language that is usable in both environments.
